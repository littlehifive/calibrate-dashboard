Calibrate expert review

See where your experts agreed and disagreed

Open the ratings file from a Calibrate labeling task. The page shows how often the experts agreed and puts each conversation next to its ratings, with room to write down what the group decides.

1

Download the ratings from Calibrate

  1. In the left menu, click Human alignment and open your labeling task.
  2. Go to the Dataset tab.
  3. Click Export CSV, above the list on the right. Your browser saves a file ending in -items.csv.
2

Open that file here

Picking up where you left off? Open the CSV you downloaded from this page last time. Your notes come back with it.

How this page works

Where do I open it?

Bookmark littlehifive.github.io/calibrate-dashboard and open it whenever you need it. It is an ordinary web page, so there is nothing to install and no account. It is online, but your file is read on your own computer and never sent anywhere.

Prefer a copy on your computer, or working without internet? Save this page (Ctrl+S, or Cmd+S on a Mac) and double-click the saved file to open it. It works the same way.

More than one project?

The page does not keep a list of projects. Each project is simply its own CSV file. Open the file for the project you are working on, and use ⋯ > Open a different file to switch.

A folder per project keeps things tidy: put the file from Calibrate in it, and save each download from this page next to it.

Where are my notes kept?

While you work, notes are saved in this browser, so closing the tab by accident loses nothing. The lasting record is the CSV you download on step 3.

Next time, open that downloaded file rather than the original from Calibrate, and your decisions come back. To hand the work to someone else, send them that file.

Sharing with the other experts?

Send them this page's address and the CSV, so they can look through it on their own computer. Or use ⋯ > Share a password-protected copy: one read-only file they can open without the CSV.

Your file stays on this computer. The page reads it inside your browser and has no way to send it anywhere.

 ·  Works offline too: save this page with Ctrl+S (Cmd+S on a Mac) and open the saved copy.
