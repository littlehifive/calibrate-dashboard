Agreement review

Turn the items CSV from a Calibrate annotation task into a rater-agreement dashboard, then record what the experts decide about each conflict.

The file is read inside this browser and never uploaded. This page is not allowed to connect to the internet at all, so conversations stay on your computer.
  1. In Calibrate, open the annotation task and download the items export (one row per conversation).
  2. Drop it above. The raters, questions and AI evaluator are found from the column names.
  3. Review the conflicts together. One person records the consensus in each conversation.
  4. Download the CSV with consensus: the original file plus consensus columns. Share a read-only view as a password-protected file.

Works offline: save this page (Ctrl/Cmd+S) and open the file later.
